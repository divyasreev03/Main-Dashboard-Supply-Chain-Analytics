# Supply Chain Analytics Dashboard

## Overview

This project is an end-to-end supply chain analytics solution that combines Python-based data analysis, SQL-based querying, and Power BI visualization.

The project analyzes operational data across inventory, suppliers, logistics, shipping, product quality, revenue, and profitability to generate meaningful business insights.

## Objectives

- Analyze inventory performance
- Evaluate supplier performance
- Understand logistics and shipping costs
- Study delivery and lead-time patterns
- Analyze product quality and defects
- Evaluate revenue and profitability
- Present key findings through interactive dashboards
